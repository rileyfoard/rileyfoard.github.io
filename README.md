# Riley Foard — Engineering Portfolio

Live at **https://rileyfoard.github.io** once it's published.

## Publish it (one time)

1. On GitHub, create a new **public** repository named exactly `rileyfoard.github.io`.
2. Click **Add file → Upload files**, drag in everything from this folder (`index.html` and the `css`, `js`, `images`, `videos`, `docs`, and `projects` folders), and click **Commit changes**.
3. Go to **Settings → Pages**, set Source to **Deploy from a branch**, branch **main**, folder **/ (root)**, and save.
4. Wait a minute, then open https://rileyfoard.github.io.

## Edit it

You can edit any file right on GitHub (open it and click the pencil icon).

- **Main page:** `index.html` (bio, skills, honors, leadership, resume, contact).
- **Project and research write-ups:** one page each in the `projects/` folder. Search for `✏️ BLURB` to find and edit each write-up.
- **Captions:** the `<figcaption>` lines under each photo or video on those pages.
- **Add a photo or video:** put it in `images/` or `videos/` and copy an existing `<figure>…</figure>` line in that project's page.

Keep every file under 100 MB (GitHub's limit). Videos play muted.
